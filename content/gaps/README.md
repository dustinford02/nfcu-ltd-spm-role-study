A gap is a missing source, an unclear boundary, or an unanswered role question. It is not a license to invent a fact.

Record: path; missing class/source; unmapped posting sentence (or not a posting-coverage gap); proposed patch; evidence needed; resolved/open status.

Preserve source and retrieval date when an employer answer resolves an unknown. Add the new source and show the changed assumption. A prep drill is never converted into an official interview question merely because it sounds plausible.

The private intake report and disclosure review remain outside the repository. Do not paste them into issues, reviews, or public gap files. Source validation is separate from UI acceptance.
