# Run a hypothetical readiness review

This is not an official interview question.

Class: prep_drill. Timebox: 25 minutes. Topics: performance-cycle-calibration, program-execution-governance, change-adoption-mentoring.

## Practice

Design a readiness review for a hypothetical cycle launch covering policy sign-off, access, data, communications, manager capability, support, and exceptions.

## Self-check instructions

Label it a proposal. Include evidence per gate, owners to confirm, and a response when evidence is incomplete.
