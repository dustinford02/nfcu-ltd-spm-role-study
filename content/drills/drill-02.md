# Sketch a reference performance cycle

This is not an official interview question.

Class: prep_drill. Timebox: 3 minutes. Topics: performance-cycle-calibration.

## Practice

Explain a general performance cycle in plain language. Label it as a reference model, then name one employer-specific detail still missing.

## Self-check instructions

Separate a general model from the actual employer calendar and approval process.
